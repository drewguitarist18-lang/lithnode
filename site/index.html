Three moves.

Draw

Drop in bots, give each team a job, its command-line tools and connectors, and wire them up. Or describe the team in one line and it gets drawn for you.

Run

Every agent is a real Claude Code, Codex or Cursor session on your machine. Watch each one work, live, in the folder you picked.

Approve

Put an approval step anywhere. The run waits for you before anything ships, and the result lands in one report.

Split it, then check it

Cut one big job into parts that agents do side by side, then put a checker team after them to verify every part.

Mix engines

Claude Code, Codex and Cursor in one flow, each with the models its plan offers.

Only the tools you allow

Switch on git, gh or python per team. Everything else stays blocked.

Local and open source

No account, no API keys, no telemetry. Your code and sign-in stay on your machine, and every line of Lithnode is on GitHub.
