How it works

Three moves. That's the whole thing.

01

Draw the team

Drop in bots, give each team a job, its CLIs and its connectors, and wire them up. Or describe the team in one line and Lithnode draws it.

02

Press run

Every agent is a real Claude Code, Codex or Cursor session. Watch each one work live, with an approval step wherever you want a say.

03

Run it again

Change one thing, like five workers instead of three, and run it again. Every run is saved, so you can see it getting faster.

CLIs and connectors

Your tools, without the bloat.

Switch on the command-line tools a team may run, like git, gh, vercel or python, and the connectors it needs, like Notion or Vercel. Everything else stays blocked, and connector tools load only when an agent searches for one, so every agent starts lean.

Built in

Everything a team needs.

Real coding agents, mixed

Not a chat imitation. Every agent is a real Claude Code, Codex or Cursor session, and one flow can mix them, with the access you give it: read, web, edit, or only the CLIs you switch on.

Split it, then check it

Cut one big job into parts that agents do side by side, then put a checker team after them to verify every part.

You stay in charge

Drop an approval step anywhere. The run waits for your go, and can ping your phone when it does.

Your Claude plan

No API keys, no extra bill. Each agent uses your own Claude, ChatGPT or Cursor sign-in, like any other session.

Describe it, get a flow

Type "plan it, build it, then three reviewers check it" and the team is drawn for you, ready to run.

Local and open source

Your code and your sign-in never leave your machine. Lithnode is a local app, and its code is on GitHub.
