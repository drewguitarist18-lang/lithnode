01

Get Lithnode

Lithnode runs your agent teams on your own computer, on the Claude, Codex or Cursor plan you already have. Connecting Claude needs version 0.1.30 or newer. If you have an older one, the app updates in one click.

Download Lithnode
02

Connect Claude

Pick where you use Claude. Lithnode has to be open while Claude works, because every run happens there.

Claude Code one click

Lithnode adds itself to Claude Code for every project. That covers the terminal and the Claude desktop app's Code tab.

  1. In Lithnode, open Settings (the cog, or Ctrl+,).
  2. Under Connect Claude, click Add to Claude Code.
  3. Start a new Claude Code session. Type /mcp to see lithnode connected.

Claude desktop app chat

The desktop app's chat runs local tools from its config file. Lithnode writes the right entry for your computer.

  1. In Lithnode, open Settings › Connect Claude and click Copy config.
  2. In Claude, open Settings › Developer › Edit Config, paste it in and save.
  3. Quit and reopen Claude. Lithnode's tools show under the tools button in a chat.

By hand any MCP client

Lithnode's MCP server runs over stdio. The installed app starts it with lithnode-cli mcp. On Windows that's:

Run this in Command Promptclaude mcp add --scope user lithnode -- "%LOCALAPPDATA%\Programs\Lithnode\server\lithnode-cli.exe" mcp

Settings › Connect Claude shows the exact command for your install, including on Mac and Linux.

03

Ask for a team

Say it the way you'd brief a person. Claude picks or builds a flow, runs it in your folder and checks on it until it's done. Tap one to copy it.

05

What Claude can do

Nine tools, all on your computer. Nothing goes through lithnode.com.

lithnode_status

Is Lithnode open, and which engines are signed in.

list_flows

Your flows and the templates to start from.

get_flow

A flow's steps in order, with each team's engine and model.

create_flow

A new flow from a description or a template.

run_flow

Start a flow on a task, in a folder.

get_run

Each step's state, files changed and the final report.

list_runs

Recent runs, newest first.

decide

Answer an approval step, when you say so.

stop_run

Stop a run. Finished work is kept.

Claude asks before it uses a tool unless you've allowed it. Runs use your own plans and keys, so they count toward your usage like any run you start in Lithnode.
